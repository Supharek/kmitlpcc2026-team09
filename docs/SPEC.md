# ส่วนที่ 2 · Wireframe (UI/UX Designer)

## วิธีส่งมอบ wireframe ให้ AI Agent — ต้องมี 2 อย่างคู่กันเสมอ

**AI อ่านรูปได้จริง แต่อ่านข้อความในรูปผิดบ่อย** โดยเฉพาะภาษาไทยตัวเล็ก
จึงต้องแยกหน้าที่กัน — รูปบอก *รูปทรง* ตารางบอก *ข้อความ*

| | 1️⃣ รูป PNG จาก Figma | 2️⃣ ตารางข้อความ (ในไฟล์นี้) |
|---|---|---|
| **บอกอะไร** | สัดส่วน, ลำดับสายตา, ระยะห่าง, อะไรควรเด่น | **ข้อความจริงทุกตัวอักษร**, ชื่อ component, สถานะ |
| **agent ใช้ยังไง** | เปิดดูเพื่อเข้าใจ layout | copy ไปใช้ตรง ๆ ห้ามแต่งเอง |
| **แม่นยำ** | ประมาณ ๆ | 100% |
| **ตอนรีวิวงานกัน** | เห็นรูปแต่ไม่รู้ว่าเปลี่ยนตรงไหน | `git diff` เห็นชัด |

> ❌ **อย่าให้ AI แปลงรูปเป็น ASCII** เสียเวลาและได้ของแย่กว่าเดิม
> ❌ **อย่าแปะแค่ลิงก์ Figma** — agent เข้าไม่ได้ ต้อง export เป็นไฟล์เข้ามาใน repo

### ขั้นตอนของ UI/UX

> 👀 **ดูตัวอย่างก่อนลงมือ:** `docs/wireframes/example-desktop.png`
> จะเห็นว่าต้องละเอียดแค่ไหน และเขียนโน้ตอะไรกำกับบ้าง

1. วาดใน Figma (หรือกระดาษแล้วถ่ายรูป — ใช้ได้จริง ไม่ต้องสวย)
2. **Export PNG @1x** แล้ววางที่ `docs/wireframes/` ตั้งชื่อว่า `<หน้า>-<breakpoint>.png`
   เช่น `home-mobile.png`, `home-desktop.png`, `quote-mobile.png`
   *(ไฟล์ละไม่เกิน ~500KB — wireframe ขาวดำไม่ควรใหญ่กว่านี้)*
3. ใส่ลิงก์รูป + **กรอกตารางข้อความ** ในหัวข้อของหน้านั้นข้างล่าง
4. commit รูปเข้า git ด้วย (`docs/wireframes/` ไม่ได้อยู่ใน `.gitignore`)

### วิธีสั่ง agent ให้อ่านรูป
